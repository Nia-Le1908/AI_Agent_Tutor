================================================
0) Cau truc project hien tai
================================================

Thu muc goc project gom cac file/chuc nang chinh:

- app.py                  : Giao dien Streamlit chinh.
- dashboard.py            : Bieu do thong ke hoc tap bang Plotly.
- controller.py           : Dieu phoi Chat RAG va sinh bai tap.
- llm_client.py           : Noi duy nhat goi LLM (retry/backoff, phat hien rate limit).
- generator.py            : Goi DeepSeek API de sinh cau hoi trac nghiem.
- adaptive_logic.py       : Dieu chinh do kho theo lich su dung/sai.
- sqlite_manager.py       : Toan bo query nghiep vu (users/questions/history/thong ke).
- db_manager.py           : Tang ket noi duy nhat (SQLite + PostgreSQL pool).
- config.py               : Doc va validate .env mot lan, source of truth cho moi module.
- config_db.py            : Facade tuong thich cho chon backend DB (khong doc .env lai).
- validation.py           : Ham kiem tra dung chung (uid, level trong [1,5], ...).
- schemas.py              : Load schema.json, validate cau hoi, chuan hoa options A-D.
- faiss_store.py          : Duong dan FAISS, doc/ghi index, cache embedding model.
- init_db.py              : Khoi tao database tu schema.sql.
- schema.sql              : Cau truc bang users, questions, history, sessions.
- schema.json             : Schema validate cau hoi AI sinh ra.
- json_parser.py          : Parse JSON cau hoi va insert vao database.
- embedder.py             : Doc PDF/DOCX, chia chunk, tao embedding va FAISS index.
- retriever.py            : Truy xuat top-k chunk tu FAISS index.
- rag_tester.py           : Danh gia retrieval bang Precision@3 va MRR.
- auth.py                 : Bcrypt + JWT + RBAC, doc/ghi users qua db_manager.
- generate_mock_data.py   : Tao du lieu demo trong mock_data/.
- requirements.txt        : Danh sach thu vien can cai.
- pytest.ini / tests/      : Bo test hermetic (python -m pytest).
- .env.example            : Mau cau hinh moi truong.

Thu muc runtime/artifact:

- data/                   : Chua SQLite DB va tai lieu PDF/DOCX cho RAG.
- vector_store/           : Chua faiss_index.bin va chunks_metadata.json.
- mock_data/              : Chua mock_questions.json va mock_db.sqlite.
- logs/                   : Chua file log runtime.

================================================
3) Tao va chinh file .env
================================================

Tao file .env tu mau:

--- Windows PowerShell ---

    Copy-Item .env.example .env

--- macOS / Linux ---

    cp .env.example .env

Mo file .env va dam bao co cac bien phu hop voi code hien tai.
Cac bien cu (GEMINI_API_KEY, LLM_PROVIDER, OLLAMA_MODEL) KHONG con duoc doc nua;
chung da bi loai khoi .env.example va config.py. Neu .env cu cua ban con gi nhung
bien do thi chung bi bo qua (khong gay loi), nhung nen xoa cho sach.

Cau hinh khuyen nghi cho FULL mode:

    DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxx
    DEEPSEEK_MODEL=deepseek-chat

    DB_TYPE=sqlite
    DB_PATH=data/ai_tutor_v5.db
    FAISS_INDEX_PATH=vector_store/faiss_index.bin
    LOG_PATH=logs/app.log
    LOG_LEVEL=INFO

    CHUNK_SIZE=256
    CHUNK_OVERLAP=50
    TOP_K=3
    EMBEDDING_MODEL_NAME=all-MiniLM-L6-v2
    DEBUG_RAG_CONTEXT=false

    # Chi can khi dung auth.py (JWT + bcrypt)
    JWT_SECRET_KEY=
    SESSION_TIMEOUT_HOURS=24

Ghi chu:

- Moi bien o tren deu duoc config.py validate luc start. Gia tri sai (vi du
  CHUNK_SIZE=128 hoac CHUNK_OVERLAP >= CHUNK_SIZE) se raise ConfigError neu ro ten bien.
- DEEPSEEK_API_KEY can cho Chat Tutor va Admin Panel sinh cau hoi.
- DB_PATH chi toi file SQLite.
- FAISS_INDEX_PATH chi toi FAISS index.
- CHUNK_SIZE phai nam trong khoang 256 den 512.
- CHUNK_OVERLAP phai nho hon CHUNK_SIZE.
- TOP_K la so chunk duoc truy xuat khi chat.

    streamlit run app.py

    - Bam Start / Load User.

7) Tao cau hoi cho Exercise:

    - Dung Admin Panel trong sidebar.
    - Nhap chu de.
    - Chon do kho.
    - Chon so luong cau hoi.
    - Bam nut sinh cau hoi va luu vao DB.

8) Dung cac tab:

    - Chat      : hoi dap dua tren tai lieu RAG.
    - Exercise  : lam cau hoi trac nghiem theo level hien tai.
    - Dashboard : xem thong ke hoc tap.

================================================
7) Troubleshooting
================================================

1) Loi "No module named ..."

Nguyen nhan:

- Chua activate .venv.
- Chua cai requirements.

Cach sua:

    .\.venv\Scripts\Activate.ps1
    pip install -r requirements.txt


2) Loi "DEEPSEEK_API_KEY is required"

Nguyen nhan:

- Dang dung Chat/Admin Generate nhung .env chua co DEEPSEEK_API_KEY.

Cach sua:

    DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxx

Sau do chay lai app.


3) Loi "FAISS index file not found" hoac "chunks_metadata.json not found"

Nguyen nhan:

- Chua build vector store.

Cach sua:

    - Dat PDF/DOCX vao data/.
    - Chay:

        python embedder.py


4) Chat khong tim thay context phu hop

Nguyen nhan co the:

- Chua co tai lieu phu hop trong data/.
- Tai lieu qua ngan hoac khong trich xuat duoc text.
- Chua rebuild index sau khi them tai lieu moi.

Cach sua:

    python embedder.py


5) Exercise bao khong co cau hoi

Nguyen nhan:

- Bang questions dang rong.
- Bo loc subject/level khong co cau hoi phu hop.
- Tuy chon bo qua cau da lam dung dang loai het cau hoi.

Cach sua:

- Dung Admin Panel de sinh cau hoi moi.
- Hoac chay DEMO mode voi mock_data/mock_db.sqlite.
- Doi subject filter ve "Tat ca".
- Tat tuy chon bo qua cau da lam dung neu can.


6) Loi "no such table"

Nguyen nhan:

- Database chua duoc khoi tao.
- DB_PATH dang tro sai file.

Cach sua:

    python init_db.py

Kiem tra lai DB_PATH trong .env.


7) rag_tester.py bao khong du 20 chunks

Nguyen nhan:

- Corpus trong vector_store co it hon 20 chunks.

Cach sua:

- Them tai lieu PDF/DOCX vao data/.
- Chay lai:

    python embedder.py


8) Khong cai duoc faiss-cpu

Nguyen nhan co the:

- Python version hoac he dieu hanh khong co wheel phu hop.

Cach sua:

- Dung Python 3.10 hoac 3.11.
- Nang cap pip:

    python -m pip install --upgrade pip

- Cai lai requirements.
